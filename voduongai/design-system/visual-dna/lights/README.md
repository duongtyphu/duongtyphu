# Lights

Asset ánh sáng: sunray, glow, halo, sparkle, constellation line.

Đặt tên: `light-<loại>` (`light-sunray`, `light-glow`, `light-halo`, `light-sparkle`), `constellation-<ngữ-cảnh>` (`constellation-genome`).

Hiện đang triển khai bằng CSS animation trong `src/app/globals.css` (`.garden-sunray`, `.garden-sparkle`, `.sanctuary-orb`, `.sanctuary-glow-soft`) — chưa có asset ảnh ánh sáng nào cần import.
