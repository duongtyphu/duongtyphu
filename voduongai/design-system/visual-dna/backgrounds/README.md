# Backgrounds

Mesh gradient, texture nền, pattern nền dùng chung — đặt tên theo chuẩn `background-<khu-vực>-<biến-thể>` (xem `../VISUAL_DNA.md`).

Hiện đang triển khai trực tiếp bằng CSS trong `src/app/globals.css` (`.gemos-bg`, `.sanctuary-bg`, `.sanctuary-bg-warm`, `.garden-scene`) — chưa có asset ảnh nền nào cần import. Nếu Founder duyệt một background dạng ảnh (không phải gradient CSS thuần), lưu vào đây theo đúng tên chuẩn.
