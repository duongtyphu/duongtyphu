# References

Reference đã được Founder duyệt ("DUYỆT"), tổ chức theo khu vực và version.

Cấu trúc mỗi reference:

```
references/<khu-vực>/<khu-vực>-reference-v<số>/
├── <khu-vực>-reference-v<số>.png   (ảnh gốc)
└── README.md                        (Ý tưởng / Màu / Layout / Typography / Animation / Feeling)
```

Xem quy trình đầy đủ (Image Import Workflow) trong `../VISUAL_DNA.md`.

## Trạng thái hiện tại

Chưa có reference nào được import. Khi Founder gửi ảnh và nói "DUYỆT", tạo thư mục con tương ứng tại đây theo đúng cấu trúc trên.
