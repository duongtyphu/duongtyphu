# Academy Product Book — Điều hướng

Thứ tự đọc khuyến nghị cho người mới tiếp cận EPIC 02 — Academy Operating System (AOS):

1. **`Academy_Blueprint.md`** — Vision, Philosophy, Product Goal, Architecture, Learning Flow,
   Capability Flow, Graduation Flow. Đọc đầu tiên.
2. **`Academy_Constitution.md`** — 10 nguyên tắc bất biến, ràng buộc cứng cho mọi Sprint sau.
3. **`Learning_Philosophy.md`** — Định nghĩa Học/Thực hành/Năng lực/Trưởng thành/Companion.
4. **`Capability_Framework.md`** — Mô hình 5 tầng (Knowledge → Practice → Capability →
   Confidence → Growth) thay thế chấm điểm truyền thống.
5. **`Learning_Path_Blueprint.md`** — Cách Learning Path sinh ra từ CKOS Collection.
6. **`Lesson_Blueprint.md`** — Cấu trúc 9 phần của 1 Lesson.
7. **`Practice_Framework.md`** — Quy định Practice (ngắn/thực tế/làm ngay/có kết quả).
8. **`Growth_Framework.md`** — 4 dấu hiệu trưởng thành, không đo Score/Điểm/Xếp hạng.

### Sprint 02 — Learning Journey Engine™

9. **`Learning_Journey_Blueprint.md`** — Journey là gì, khác Learning Path ở đâu, kiến trúc code.
10. **`JourneyRules.md`** — Ngưỡng chuyển giai đoạn, khi nào gợi ý Practice/Reflection, giọng
    nói Companion Guidance.
11. **`Growth_Checkpoint_Standard.md`** — Chuẩn Growth Checkpoint (2 câu hỏi cố định, không
    chấm điểm).
12. **`Templates/Journey.template.md`**, **`Templates/Checkpoint.template.md`**,
    **`Templates/GrowthPrompt.template.md`** — mẫu tham chiếu khi mở rộng Journey Engine.

Báo cáo Sprint: `EPIC_02_Sprint_01_Review_Report.md`, `EPIC_02_Sprint_02_Review_Report.md`.

## Quan hệ với CKOS

Academy là tầng đọc trên CKOS (`/docs/CKOS/`), không thay thế. Đọc `docs/CKOS/CKOSConstitution.md`
trước khi đọc bộ tài liệu này nếu chưa quen thuộc với CKOS.
